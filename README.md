# AnyFile Converter

## &#x20;How to Run

1. Download and extract the project ZIP file.
2. Install Python on your computer.
3. Install FFmpeg and LibreOffice if you want to use video and document conversion features.
4. Open CMD inside the project folder.
5. Run these commands:

```bash
pip install -r requirements.txt
python app.py
```

6. Open your browser and visit:

```text
http://127.0.0.1:5000
```

## How to Use

1. Open the website.
2. Select the file you want to convert.
3. Choose the output format.
4. Click the Convert button.
5. Wait for conversion to finish.
6. Download your converted file.

## Features

- PDF to Word, Excel, and PowerPoint
- Image format conversion
- Video to MP3 conversion
- PDF merging and splitting
- Simple and responsive interface

## Technologies

Python, Flask, HTML, CSS, JavaScript, FFmpeg, and LibreOffice.

**Note:** The website runs locally on your computer. Online access requires deployment to a hosting service.
